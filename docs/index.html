Questions

Do I need to install anything?+

No. Cuisine.AI works in the browser on an iPad, a phone or a computer. You can add it to the home screen so it opens like an app.

Does every employee need an account?+

No. The restaurant has one account. On the shared tablet, staff pick their name when they record something, so you know who did what. Settings stay behind the admin PIN.

What if the AI misreads an invoice?+

Nothing is saved until someone confirms. You see every line before it reaches the stock, and lines the AI is unsure about are highlighted so they get checked first.

Can it handle credit notes, discounts and packs?+

Yes. Credit notes take stock back out, discount lines are counted, and packs are converted: “2 cartons x 6” becomes 12 bottles, “6 x 75 cl” becomes 4.5 L.

Can I connect my temperature sensors?+

Yes. Each restaurant gets an API key so connected probes can send readings automatically.

How long does it take to set up?+

Create the account, add your fridges and team, then scan your first invoices: products are created from them, so you don't have to type a catalogue.
