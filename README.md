# Cuisine.AI website

The public product website for [Cuisine.AI](https://cuisine-ai-app.onrender.com). The application itself lives in a separate, private repository.

- `src/` – the page, written in React + Tailwind
- `npm run build` – renders it to static HTML in `docs/`, which GitHub Pages serves
- `src/config.ts` – the address of the app that the "Log in" / "Start free" buttons open
